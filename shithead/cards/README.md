# Kartenmotive

Die 52 SVG-Dateien in diesem Ordner basieren auf dem **English pattern**-Kartendeck
von **Dmitry Fomin**, veröffentlicht auf Wikimedia Commons unter **CC0 1.0**
(Public Domain Dedication) — freie Nutzung ohne Bedingungen, auch kommerziell.

Quelle: https://commons.wikimedia.org/wiki/File:English_pattern_playing_cards_deck.svg

Die Dateien wurden für den Web-Einsatz optimiert (Inkscape-Metadaten entfernt,
Koordinaten auf 2 Nachkommastellen gerundet, wiederholte `style`-Attribute zu
CSS-Klassen zusammengefasst) — von 2,2 MB auf 1,05 MB.

Benennung: `<Rang><Farbe>.svg`, z. B. `KS.svg`, `10H.svg`, `AD.svg`
Ränge `2`–`10`, `J`, `Q`, `K`, `A` · Farben `S`pades, `H`earts, `D`iamonds, `C`lubs
